# Revisão visual glassmorphism

Aplicada uma revisão global do designer do HealthLink Sentinel.

## Diretrizes aplicadas

- Superfícies com transparência controlada, blur e brilho interno sutil.
- Cards, painéis, menus e modais com bordas arredondadas.
- Botões e campos com cantos suaves e feedback de hover consistente.
- Contraste preservado para estados operacionais: ciano/verde, âmbar e vermelho.
- Fundo com gradientes radiais discretos para manter aparência de plataforma de missão crítica.
- Nenhuma regra removeu ações ou funcionalidades existentes.

## Validação

- `npm.cmd run typecheck` aprovado.
- `npm.cmd run build:web` aprovado.
