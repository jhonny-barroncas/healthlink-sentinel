# Menu contextual do mapa

Ao clicar com o botão direito em um marcador de unidade no mapa estadual, o HealthLink Sentinel exibe um balão glassmorphism com as opções:

- Ping
- Tracert
- Adicionar equipamento

O menu também pode ser fechado pelo botão `×`. As ações Ping e Tracert encaminham o operador para a unidade selecionada, mantendo a execução de diagnósticos centralizada na integração Zabbix. O vínculo entre host e equipamento continua sendo o fluxo oficial para executar comandos reais.
