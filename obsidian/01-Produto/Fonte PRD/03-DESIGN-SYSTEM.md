# Design System Corporativo

O sistema deve transmitir:

-   Confiança
-   Segurança
-   Estabilidade
-   Missão crítica

Referências: - Microsoft Azure - Cisco Meraki - Fortinet - VMware -
ServiceNow

Evitar: - Visual gamer - Neon - Excesso de animações - Aparência de
startup

Priorizar: - Interface corporativa - Dark mode profissional - Hierarquia
visual clara - Poucas cores com significado operacional
