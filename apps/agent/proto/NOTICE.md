# Starlink protobufs

Os arquivos `.proto` deste diretório foram derivados do projeto
[Eitol/starlink-client](https://github.com/Eitol/starlink-client) e são usados
somente para a comunicação gRPC local de leitura do agente HealthLink.

O projeto de origem é distribuído sob licença MIT. Nenhum segredo, cookie ou
credencial da Starlink é armazenado neste diretório.
